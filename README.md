# 💜 ZenMC Tiers | Rankings de PvP (South America)

Este repositorio aloja la interfaz de la Tier List dinámica de la comunidad ZenMC. Esta herramienta permite a los jugadores visualizar y filtrar el ranking de los mejores jugadores de PvP en diferentes modalidades.

### ✨ Características Principales

* **Rankings Dinámicos:** La tabla se ordena en tiempo real al hacer clic en las diferentes modalidades (Overall, Sword, NetPot, CristalPvP, UHC, SMP).
* **Sistema de Puntuación:** El ranking 'Overall' se calcula según el Tier más alto alcanzado por el jugador (HT1 es la máxima puntuación).
* **Búsqueda:** Búsqueda rápida de jugadores por nombre.
* **Perfiles (Modal):** Haz clic en el nombre de cualquier jugador para ver su ficha completa y todos sus Tiers.

### ⚙️ Estructura del Proyecto

El proyecto está diseñado para ser completamente estático y fácil de desplegar.

* `index.html`: Contiene el 100% del código (HTML, CSS y JavaScript) en un solo archivo para garantizar un despliegue perfecto en GitHub Pages.
